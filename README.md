## 📌 Sobre o Projeto

Este repositório contém o código-fonte do meu **Portfólio Pessoal**, desenvolvido para apresentar meus principais projetos, habilidades técnicas, experiência acadêmica e formas de contato.

A aplicação foi planejada com foco em **performance, responsividade e clean UI**, garantindo uma navegação fluida tanto em dispositivos móveis quanto em desktops.

🔗 **Acesse o portfólio online:** [portfolio-danilo-kaizer.netlify.app](https://portfolio-danilo-kaizer.netlify.app/)

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ferramentas:

- **Frontend:** HTML5, CSS3, JavaScript / TypeScript (ou Angular / React)
- **Styling & UI:** CSS Modules / Tailwind / Bootstrap (ajuste conforme aplicável)
- **Hospedagem & Deploy:** [Netlify](https://www.netlify.com/)
- **Versionamento:** Git & GitHub

---

## ✨ Funcionalidades

- 👨‍💻 **Apresentação Pessoal:** Breve introdução sobre minha trajetória e interesses na área de desenvolvimento de software.
- 🛠️ **Habilidades (Skills):** Exibição das principais linguagens, frameworks e ferramentas com as quais trabalho.
- 📁 **Projetos em Destaque:** Módulos com descrição, tecnologias usadas e links diretos para os repositórios/demos.
- 📬 **Contato:** Seção dedicada para envio de mensagens ou links para redes profissionais (LinkedIn, GitHub, E-mail).
- 📱 **Design Responsivo:** Layout adaptável para smartphones, tablets e monitores de alta resolução.
